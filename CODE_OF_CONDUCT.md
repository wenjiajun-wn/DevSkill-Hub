# Code of conduct

We aim for a welcoming, useful developer community. Treat contributors with respect regardless of background, identity, experience, or preferred tools.

- Discuss ideas and evidence; avoid personal attacks, harassment, discrimination, threats, and unwanted attention.
- Give constructive feedback and accept corrections. Credit others' work and respect their licenses.
- Keep issues and pull requests relevant. Do not post credentials, personal information, spam, or misleading claims.

Maintainers may edit or remove inappropriate content, close disruptive discussions, or restrict participation. Decisions should be proportionate, explained where possible, and open to a respectful request for reconsideration.

Report concerns through GitHub's **Report content** action on the relevant content. For a non-sensitive project concern, open an issue with the minimum necessary context. Do not publish private details in an issue. The maintainer should add a private reporting contact before the first public release; no private project reporting channel is currently configured.

我们欢迎不同背景的贡献者。请围绕事实和技术问题讨论，尊重署名和许可证，不发布骚扰、歧视、隐私或凭据。可通过 GitHub 的内容举报入口报告不当行为；维护者在公开发布前应补充私密联络方式。
