# Registry glossary / 目录术语表

| Term | Meaning |
| --- | --- |
| Skill entry / Skill 条目 | One curated developer workflow, identified by a stable catalog ID. |
| Source repository / 来源仓库 | The upstream GitHub repository containing one or more skills. Its stars belong to the repository as a whole. |
| Star observation / Star 采集 | A successful API observation of a repository's star count at a recorded time. |
| Content review / 内容审查 | Inspection of source content, license evidence, installation documentation, and category fit at a recorded revision. |
| Installation review / 安装说明审查 | Confirmation that the published installation instructions have a traceable source. |
| Installation smoke test / 安装冒烟测试 | Actual installer execution with checks of installed identity and supporting resources in a recorded environment. |
| Functional smoke test / 功能冒烟测试 | A bounded executable check of a tool or workflow against specified acceptance criteria. |
| Effectiveness evaluation / 效果评估 | A recorded task-level evaluation of an agent using the skill; broader improvement claims need a suitable baseline. |
| Unknown stars / 未知 Star | No verified observation is available. This differs from an observed count of zero. |
| Monitoring baseline / 监测基线 | Reviewed content hashes against which later upstream changes are detected. Detection does not itself renew a review. |
